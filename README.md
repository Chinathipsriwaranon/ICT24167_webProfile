## ☁️ โครงสร้าง Cloudflare Ready (Pages, D1 & R2)

โปรเจกต์นี้ได้รับการวางโครงสร้างพร้อมใช้งานสำหรับ **Cloudflare Pages** ทันที:

```
├── index.html                   # ไฟล์หลัก Single-Page Portfolio
├── css/
│   └── style.css                # สไตล์ Glassmorphism, Animations, Dark/Light Themes
├── js/
│   ├── app.js                   # Application State, Scroll Spy, Theme, Hero/Edu/Skills Renderers
│   ├── data.js                  # Initial Bilingual ICT Student Data & Seed Content
│   ├── i18n.js                  # Internationalization Engine (TH / EN)
│   ├── projects-crud.js         # Projects CRUD, Filtering & Local Image Upload
│   ├── certs-crud.js            # Certifications CRUD & Local PDF Upload/Viewer
│   └── toast.js                 # Floating Glassmorphic Toast Notification System
├── functions/api/               # Cloudflare Pages Functions (Edge Serverless)
│   ├── projects.js              # GET, POST, PUT, DELETE เชื่อมโยงกับ Cloudflare D1
│   ├── certifications.js        # GET, POST, PUT, DELETE สำหรับตารางใบรับรอง
│   ├── upload.js                # จัดเก็บไฟล์ภาพ & PDF บน Cloudflare R2 Storage
│   ├── profile.js               # จัดการข้อมูลประวัตินักศึกษา
│   └── files/[key].js           # Route ให้บริการดาวน์โหลดไฟล์จาก R2 Bucket
├── schema.sql                   # ฐานข้อมูล SQLite สำหรับ Cloudflare D1 พร้อมข้อมูล Seed Data
├── wrangler.toml                # การตั้งค่า Cloudflare Configuration
└── README.md                    # เอกสารคู่มือการใช้งาน
```

## 🚀 วิธีการทดสอบและเปิดใช้งาน

### 1. ทดสอบใช้งานบนเครื่อง Local
คุณสามารถดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนเบราว์เซอร์ได้ทันที หรือรัน Local Web Server:
```bash
# ใช้ Python HTTP Server แบบเร็ว
python -m http.server 8080
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:8080`

### 2. ดีพลอยขึ้น Cloudflare Pages (Production)
```bash
# 1. ติดตั้ง Wrangler CLI (หากยังไม่มี)
npm install -g wrangler

# 2. ล็อกอินเข้า Cloudflare
npx wrangler login

# 3. สร้างฐานข้อมูล D1
npx wrangler d1 create ict_portfolio_db

# 4. นำเข้า Schema และ Seed Data เข้า D1
npx wrangler d1 execute ict_portfolio_db --file=./schema.sql

# 5. สร้าง R2 Bucket สำหรับเก็บไฟล์
npx wrangler r2 bucket create ict-portfolio-storage

# 6. ดีพลอยขึ้น Cloudflare Pages
npx wrangler pages deploy . --project-name ict-portfolio
```
